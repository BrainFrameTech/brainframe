# any-sync protocol

- **Status:** placeholder — not started
- **Part of:** the [P2P sync sequence](README.md), document 2 of 7

## What this document will answer

How any-sync works, described in its own terms: its parts (nodes, spaces,
the sync and file layers), how devices find each other and connect, how
identity and keys work, what is encrypted and with which key, and what each
kind of node can see. It describes and does not judge; the judging is done in
[document 3](03-any-sync-fit.md).

## What it needs first

An accepted [threat model](01-threat-model.md), so that the description
covers everything the analysis will ask about. The sources are any-sync's
published protocol documents and its MIT-licensed code only. Never the
Anytype client code, which is under a source-available licence (see #67).

## What it hands on

The description that [document 3](03-any-sync-fit.md) checks against the
threat model.
